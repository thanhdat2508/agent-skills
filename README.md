# Agent Skills Collection

A comprehensive collection of 100+ global skills and playbooks for AI agents (Antigravity / Gemini / Claude Code / Copilot), designed to supercharge autonomous workflows, software engineering, architecture, code quality, testing, animations, and security.

## Overview

This repository contains modular skills structured with `SKILL.md` definitions, guidelines, prompt playbooks, and references across multiple domains:

- **Frontend & Modern Web:** Next.js, Nuxt, Vue, Pinia, UnoCSS, Vite, Vitest, Frontend Design, A11y, GSAP (Core, React, Plugins, Timelines, ScrollTrigger).
- **Backend & System Architecture:** NestJS, Senior Architect, Senior Backend, Senior Data Engineer, Database Architect, Nitro.
- **Engineering Best Practices & Principles:** Clean Code, TDD, TypeScript Best Practices, Refactoring, Spec-Driven Development, Boundary Discipline, Idempotent Operations.
- **Security & Reliability:** Security Audit, Agent Red-Teaming, Verification Skills.
- **Tools & Ecosystem:** Docker, PNPM, Remotion (Captions, Maps, Markup, Render, Studio), Machine Learning Model Training.
- **Agent Workflows & Personas:** Swarm, Reflect, Sharpen, Poteto Mode, Humanizer, and more.

## Usage

Each skill directory contains:
- `SKILL.md`: Metadata (name, description, triggers) and actionable instructions for the AI assistant.
- Reference materials, scripts, or examples when applicable.
